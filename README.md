### 💡 Overview 
JH. Portfolio is my personal website showcasing my software development and UI/UX design projects.
It combines creativity and technology — built to highlight both code and visual design with a clean and modern aesthetic.

This portfolio also serves as my professional profile, including projects, skills, and contact information.

### ⚙️ Tech Stack
- ⚛️ Next.js — React framework for fast and optimized websites
- 🎨 TailwindCSS — Utility-first CSS for modern responsive layouts
- 🌙 Next-Themes — Light/Dark mode toggle
- 💬 Headless UI — Accessible components
- 🧩 Lucide Icons — Simple and consistent icon set


### 📂 Sections
- 🧭 Header — Sticky navigation & theme switching
- 💼 Work — Project gallery with details
- ⚙️ Skills — Technologies and tools
- 🙋 About — Personal background
- 📄 Resume — Academic & professional summary
- ✉️ Contact — Direct links for communication
